# Appearance & Settings

Customize the extension's theme and fine-tune behavior from a centralized Settings hub.

## Dark Mode / Theme Toggle

1. Open the popup or the Options page
2. Click the theme toggle button (usually a sun/moon icon) to cycle through **Light → Dark → System**

   ![Theme toggle button](../images/features/appearance-and-settings-01.png)

3. The chosen theme is synced across the popup and the Options page immediately

   ![Dark mode applied across popup and options](../images/features/appearance-and-settings-02.png)

4. **System** mode automatically follows your OS's `prefers-color-scheme` setting and updates live if you change it

## Settings Page

Go to **Options → Settings** tab (gear icon, rightmost tab) to access all preferences in one place:

![Settings tab overview](../images/features/appearance-and-settings-03.png)

| Setting | Description | Default |
|---|---|---|
| **Theme** | Light / System / Dark | System |
| **Trash Retention** | Days to keep deleted items (1–90) | 15 days |
| **New Tab Position** | Next to current tab / End of tab bar | Next to current |
| **Default Category** | Auto-select category when adding new URLs | None |
| **Context Menu Order** | Drag to reorder the top-level sections | — |
| **Preset Layout** | Flat list vs. grouped submenus | — |
| **Popup Defaults** | Default sort mode and whether the query bar appears automatically | — |
| **Smart Suggestions** | Toggle the automatic URL template suggestion | Enabled |
| **Assigned Keyboard Shortcuts** | View and remove all keyboard shortcut assignments | — |
| **Omnibox Search** | Reference guide for using the `cs` keyword in the address bar | — |

### Step-by-Step: Changing a Setting

1. Go to **Options → Settings**
2. Locate the setting you want to change (e.g., **Default Category**)
3. Update the value using the dropdown, toggle, or input field
4. The change is saved automatically and applied immediately — no separate "Save" button required

   ![Changing the Default Category setting](../images/features/appearance-and-settings-04.png)
