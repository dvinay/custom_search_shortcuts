# Productivity Features

A collection of tools in the popup and options page that speed up managing and using your shortcuts day to day.

## Duplicate Shortcuts

1. Go to **Options → Search URLs**
2. Click the **Duplicate** icon on any saved URL
3. The **Add Search URL** form is pre-filled with that shortcut's data for you to review and tweak
4. Click **Add URL** to save it as a new, separate shortcut

![Duplicating a search URL](../images/features/productivity-01.png)

## Popup Quick Access

1. Click the extension icon to open the mini-dashboard popup
2. From here you can search, launch, and manage shortcuts without opening the full Options page

![Popup quick access dashboard](../images/features/productivity-02.png)

## Search & Filter

1. In the popup, type into the search box at the top
2. The shortcut list filters instantly as you type

![Search and filter shortcuts in the popup](../images/features/productivity-03.png)

## Sort Modes

1. In the popup, use the sort control to switch between:
   - **Alphabetical** (default)
   - **Most Used**
   - **Recently Used**

![Sort mode selector in the popup](../images/features/productivity-04.png)

## Query Bar

1. With the popup open, press `Alt+Q` (or enable it to show by default in Settings)
2. Type a query directly into the query bar and press Enter to test a search without leaving the popup

![Query bar in the popup](../images/features/productivity-05.png)

## Copy URL

1. In the popup or Options list, click the **Copy** icon on a shortcut
2. The final resolved search URL is copied to your clipboard

![Copying a shortcut's URL](../images/features/productivity-06.png)

## Usage Stats

1. Each shortcut displays a small counter badge showing how many times it has been used
2. Counters update automatically every time you use that shortcut

![Usage counter badge on a shortcut](../images/features/productivity-07.png)

## New Tab Positioning

1. Go to **Options → Settings → New Tab Position**
2. Choose whether shortcut results open **next to your current tab** or at the **end of the tab bar**

![New Tab Position setting](../images/features/productivity-08.png)

## Smart URL Suggestions

1. When adding a new Search URL, paste a URL copied directly from a search results page (e.g., `https://www.google.com/search?q=chrome+extensions`)
2. The extension detects the search query portion and automatically suggests replacing it with the `%s` placeholder
3. This behavior can be toggled on/off in **Options → Settings → Smart URL Suggestion**

## Bulk Actions

1. In **Options → Search URLs**, select multiple shortcuts using their checkboxes

![Selecting multiple shortcuts for bulk action](../images/features/productivity-09.png)

2. Use the bulk action bar to:
   - **Delete** all selected shortcuts (moved to Trash)
   - **Export** just the selection
   - **Move** the selection to a different category

![Bulk action bar with delete, export, and move options](../images/features/productivity-10.png)
